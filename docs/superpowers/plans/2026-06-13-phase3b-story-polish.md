# Phase 3b — 운세 스토리 폴리시 (애니메이션 + 콘텐츠 보강)

> 단일 프론트 트랙. 사용자 라이브 피드백: "스토리 너무 심심함, 탭 넘김 애니메이션, 상단 바 세그먼트(인스타식), 요약 차트 애니메이션".

**Goal:** 운세 스토리(`/fortune`)를 인스타 스토리 수준의 동적 경험으로 — 카드 전환 애니메이션, 세그먼트 프로그레스 바, 요약 차트 등장 애니메이션, 카드별 시각 보강.

**대상 파일:** `apps/web/components/fortune/FortuneStoryPage.tsx`, `StoryCard.tsx`, `SummaryCard.tsx`, (필요 시) `lib/fortune/*` + 테스트. **다른 영역(홈·만세력·채팅) 수정 금지** — 병렬 디자인 트랙과 충돌 방지.

**디자인 기준:** design.md §2.4(스토리 색)·§5.6, `@sajuguri/design`의 `story`·`ohaeng` 토큰. 이모지 금지, max-w 640px 풀스크린.

---

### T1. 세그먼트 프로그레스 바 (인스타 스토리식)
현재 상단 바가 한 줄(단일 진행률)이라면 → **카드 개수만큼 세그먼트로 분할**. 각 세그먼트: 지난 카드=꽉 참(옐로), 현재 카드=진행 중(애니메이션 채워짐 또는 즉시 꽉 참), 이후=빈 칸(반투명 흰색). 탭마다 갱신. 순수 레이아웃 계산 있으면 `lib/fortune`에 분리+테스트.

### T2. 카드 전환 애니메이션
탭(다음/뒤로) 시 카드가 **슬라이드+페이드 인** (다음=오른쪽에서, 뒤로=왼쪽에서). CSS transition/keyframe로 구현 (외부 애니메이션 라이브러리 금지 — Tailwind + inline style/keyframes). `prefers-reduced-motion` 존중(애니메이션 끔). 점수 숫자는 카운트업(0→점수) 애니메이션 선택 적용.

### T3. 카드별 시각 보강 (심심함 해소)
- intro 카드: 일진 간지를 큰 세리프(font-serif)로 + 오행색 강조 + 마스코트
- category 카드: 카테고리별 **배경에 은은한 오행 그라디언트 오버레이**(스토리 딥틸 위에 살짝), 점수에 따라 강조 톤. 큰 점수 타이포 유지
- caution/color 카드: 색 운세는 추천 색을 실제 색 스와치로 표시
- 모든 카드 하단에 카드 인덱스 점(dot) 인디케이터 또는 미니 힌트(단 "탭하여 계속" 텍스트는 금지 — 사용자가 뺐음)
- 카드 등장 시 텍스트 stagger(헤드라인 먼저, body 살짝 늦게) 페이드

### T4. 요약 카드 차트 애니메이션
SummaryCard의 카테고리 점수 바 6개가 **마운트 시 0→점수로 차오르는 애니메이션** (stagger, 각 100ms 지연). 키워드 타이포 등장 효과. 이미지 저장(캔버스) 기능은 **애니메이션과 무관하게 최종 상태로 렌더**되어야 함 — 캔버스는 정적 값 사용(애니메이션은 DOM에서만).

### T5. 검증
`pnpm --filter web build && test && typecheck` 그린. 애니메이션 로직 중 순수 계산은 테스트. dev 컨테이너(3001) `/fortune`에서 육안 확인(컨트롤러가 머지 후 수행).
