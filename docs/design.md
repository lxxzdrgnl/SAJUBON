## 3. 브루탈 강도 2단계

| 강도 | 스타일 | 적용 |
|---|---|---|
| **풀 브루탈** | `border: 2px solid #1A1A1A` + `box-shadow: 4px 4px 0 #1A1A1A` (작은 요소는 2~3px) | 배너, CTA 버튼, 활성 카드, 태그 칩, 탭 바, 입력바 |
| **저강도** | `border: 1.5px solid #EBE3D2`, 섀도 없음 | 장문 텍스트 카드(리포트 본문), AI 말풍선, 비활성 목록 카드 |

- 라운딩: 카드 16px · 버튼 11px · 칩 10px · 필 999px · 폰 프레임/시트 22px+
- 활성/강조 카드는 보더와 섀도를 `--orange`로 교체 (아코디언 펼침, 다음 대운 카드)

## 4. 컴포넌트 규칙

### 4.1 칩 (통일 규칙)
모든 칩 = 잉크 보더 2px + 미니 오프셋 섀도(2px). **의미는 배경 틴트로만**:
- 일반(격국·용신·강약): 화이트
- 길신: `--teal-tint` + 텍스트 `#00665F`
- 흉살: `--orange-tint` + 텍스트 `#B34800`
- 첨부 만세력 칩(채팅): `--teal-tint`, 점선 보더 = 추가 버튼

### 4.2 아이콘
**UI 요소에 이모지 금지.** 미니멀 스트로크 SVG 세트 사용 (24px viewBox,
`stroke-width: 2`, round cap/join): home, grid(만세력), chat, user, doc, bolt,
moon, share, redo, link, cal, set, down.

### 4.3 하단 탭 바
4탭 `홈 · 만세력 · 상담 · 마이`. 플로팅(좌우 14px, 바닥 14px), 풀 브루탈 카드,
활성 탭 = 옐로 배경 + 잉크 텍스트, 비활성 = `#A09880`. 아이콘 위 + 라벨 아래.

### 4.4 버튼
- 주요: 옐로 배경 / 강행동: 오렌지 배경+흰 글자 / 보조 행동(공유): 틸 배경+흰 글자
- 모두 잉크 보더 + 오프셋 섀도, 굵기 800

### 4.5 말풍선 (채팅)
- 유저: 옐로 배경 + 잉크 보더 2px, 우하단 꼬리 (radius 16/16/4/16)
- AI: 화이트 + **틸 보더 1.5px**, 좌하단 꼬리, 왼쪽에 마스코트 아바타 30px
- tool 결과 인라인 카드: 풀 브루탈 카드, AI 아바타 들여쓰기에 정렬

## 5. 화면별 확정 디자인 (목업 v10 기준)

### 5.1 홈 (허브)
로고+마스코트 헤더 → **옐로→오렌지 그라데이션 운세 배너** (마스코트 + "오늘의 운세",
잉크 텍스트 — §3 그라데이션 예외) → "이런 건 어때?" 기능 카드 목록 (리포트·상담 =
풀 브루탈, 한 번 물어보기·coming soon = 저강도).

### 5.2 만세력 목록 + 입력폼
- 목록: [+새 만세력 등록] 옐로 버튼 → 카드(아바타·이름·생년월일시, 탭=분석 화면,
  버튼 [리포트(오렌지)] [상담(화이트)])
- 입력폼: 이름* / 출생지 검색(미입력 시 서울) / 생년월일·시각 + 시간 모름 체크 /
  양력·음력·윤달 세그먼트(활성=옐로) / 성별 세그먼트 / [만세력 보기] 오렌지 CTA.
  하단에 "게스트도 바로 볼 수 있어요" 안내

### 5.3 만세력 분석 — "일주 히어로 + 기둥 카드"
1. **일주 히어로** (옐로 풀 브루탈): "MY 일주" 라벨 → 일주 한자 42px(세리프) →
   일주명 → **일주별 한 줄 캐릭터 카피** (60갑자, `ilju.json` 파생)
2. 태그 칩 줄 (§4.1 규칙)
3. **기둥 카드 8장** (천간 4 + 지지 4): 오행 틴트 배경, 한자 26px + 한글·오행 +
   십성. 일주 기둥만 오렌지 보더·섀도. 생일 라벨 ★
4. 12운성·신살·지장간 상세 (접이식, 저강도)
5. **오행 밸런스 카드**: "73/100 보통" 블랙 뱃지(잉크 배경+옐로 글자) + 오행 5색
   가로 바 + 판정 칩(과다=오렌지 틴트, 부족=틸 틴트) + 한 줄 해설.
   펜타그램(기존 컴포넌트 리스킨)과 바 차트 탭 전환
6. **십성 구조 카드**: conic 도넛(중앙 "핵심 구조") + 6항목 범례
7. CTA: [AI 리포트 생성(오렌지)] [상담하기(화이트)]

> ⚠️ 목업은 축약본. 실제 구현은 기존 분석 기능 **전량 유지**: 대운/월운/연운
> 슬라이더, 일진 캘린더, 합충 패널, 신살 테이블, 강약 바, 오행 특성 참고표 등
> `components/saju/*` 전체를 이 디자인 언어로 리스킨.

### 5.4 10탭 리포트
원국 요약(저강도, 접이식) → 안내 문구("각 제목을 클릭하면 해설이 펼쳐져요") →
**헤드라인 아코디언**: `# 카테고리` 오렌지 태그 + 결론형 헤드라인 15.5px/800 +
화살표. 펼침 = 오렌지 보더·섀도, 본문은 점선 구분선 아래 (3~4문단, 마지막에
"현실 조언" 박스 `#FFF4E3`). 요청 주제 탭은 오렌지 "요청" 뱃지 →
올해의 흐름(월별 행: 월=오렌지 굵게 + 키워드—메모) → 대운 비교 카드(현재=저강도,
다음=오렌지 보더 풀 브루탈) → [공유(틸)] [다시 생성(화이트)]

### 5.5 채팅
헤더(← 세션명) → 첨부 칩 줄 → 메시지(§4.5) + tool 인라인 차트 카드 →
입력바(+ 원형 버튼 / 필 입력창 / 오렌지 전송 원형 버튼, 모두 풀 브루탈 플로팅)

### 5.6 오늘의 운세 스토리
진입: 홈 배너 → **만세력 선택 시트** (저장 목록 — 본 만세력은 "다시 보기" 표시,
+직접 입력하기). 안내 캡션 없음.
스토리: 딥 틸 풀스크린, 상단 프로그레스 바(채움 옐로), 탭 네비(우=다음 좌=뒤로,
힌트 문구 없음, ✕ 닫기). 카드 구성: 질문 라벨(14px) → 점수 54px 오렌지 →
헤드라인 26px/900 → 본문. 이모지 없음. 인트로·요약 카드에 마스코트.
**요약 카드**: 날짜 + "너의 하루 요약" + 카테고리 가로 점수 바 6개 + "오늘의
키워드" 인용 타이포 + [이미지 저장(옐로 필)] [링크 공유(고스트)]

### 5.7 마이
프로필 카드(마스코트+이름+마스킹 이메일) → **내 리포트** 목록: 헤드라인 +
`생성일 · 대상 만세력(틸 강조) · 요청 주제` → 기록(운세 기록 날짜·만세력 병기,
공유 관리, 설정) — 행 구분선 리스트
